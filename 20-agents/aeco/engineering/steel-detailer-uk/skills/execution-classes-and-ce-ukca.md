# Execution classes & CE / UKCA marking (UK)

- Since **1 July 2014**, fabricated structural steelwork supplied in the UK must conform to **BS EN 1090** and be **CE-marked** (now **UKCA** in Great Britain) — conformity assessed under **BS EN 1090-1**, execution to **BS EN 1090-2**.
- The project's **Execution Class — EXC1, EXC2, EXC3 or EXC4** (EXC4 the most onerous) — drives the fabrication, inspection / NDT and documentation requirements. It is derived from **Consequence Class × Service Category × Production Category** via **BS EN 1090-2 Annex B / Table B.3**; **if no class is specified, EXC2 applies.**
- The **NSSS** main body covers **EXC2** (with an Annex for EXC3, static structures). Welding quality management ties to the class: **BS EN ISO 3834-3** for EXC2, **BS EN ISO 3834-2** for EXC3.
- The execution class shapes the *rigour* of the fabrication package and the factory production-control file — not the drawing geometry.
