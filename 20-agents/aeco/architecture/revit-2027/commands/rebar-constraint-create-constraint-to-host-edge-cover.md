# rebar-constraint-create-constraint-to-host-edge-cover

Lifecycle: single

This method creates a constraint of 'ToHostEdgeCover' type for a given RebarConstrainedHandle.The RebarConstrainedHandle should belong to a Free Form Rebar and must be allowed to constrain to host edges.The RebarConstrainedHandle that is constrained 'ToHostEdgeCover' must allow offset value.
